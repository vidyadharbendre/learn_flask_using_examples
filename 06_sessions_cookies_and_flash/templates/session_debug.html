3. Signed ≠ encrypted — prove it yourself

Copy the value of the session cookie above and run this in a terminal. You will read your own cart back in plain text: 

python - <<'PY'
import base64, zlib
raw = "PASTE_THE_SESSION_COOKIE_HERE"
# Format: <payload>.<timestamp>.<signature>
# A LEADING dot means the payload is zlib-compressed, so check `raw` first.
if raw.startswith("."):
    payload, decode = raw[1:].split(".")[0], zlib.decompress
else:
    payload, decode = raw.split(".")[0], (lambda b: b)
padded = payload + "=" * (-len(payload) % 4)
print(decode(base64.urlsafe_b64decode(padded)))
PY

The signature after the last . stops you changing the value without the SECRET_KEY — it does not stop you reading it. Never put a password, API key or card number in a session.
