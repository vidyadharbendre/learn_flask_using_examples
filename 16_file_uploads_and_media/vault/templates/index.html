{# enctype="multipart/form-data" is MANDATORY for file uploads. Without it the browser sends only the FILENAME as an ordinary text field: request.files is empty and request.form contains the name. This is the single most common upload bug, and it produces no error — just a mysteriously missing file. #}
{# `accept` is a CONVENIENCE: it filters the file picker's default view. It is not a constraint — a user can pick "All files", and curl ignores it entirely. The server sniffs the contents regardless. #}

Try to break it. The server never trusts the filename, the extension, or the declared content type:
  • Rename photo.png to photo.pdf — accepted, and stored as .png, because the bytes decide.
  • Rename a text file to .jpg — rejected.
  • Upload a file called ../../etc/passwd — stored under a random name; the path is never built from your text.
  • Upload an SVG — rejected. An SVG is XML that can contain <script>.
